# DMOI v0.2 Design — External Validation

**Status:** Design draft. Decisions needed before any implementation work.

## Why external validation matters

DMOI v0.1's biggest weakness, as flagged in the v0.1 README, is single-cohort
evaluation. 5-fold CV on TCGA-BRCA tells us the model is internally consistent
and that calibration generalizes within the cohort, but it does NOT tell us
the model generalizes to a different cohort with different sample handling,
batch effects, and sequencing platforms.

## The critical pre-flight finding

**METABRIC is NOT a drop-in external cohort for DMOI as it currently stands.**

METABRIC's molecular profiling:
- **Expression:** Illumina HT-12 v3 microarray (~48k probes covering ~24k genes).
- **Copy number / SNV:** Affymetrix SNP 6.0.
- **Methylation:** **None.** METABRIC does not have HM450 (or any
  methylation array) data.

DMOI v0.1's architecture takes RNA (20,530 genes) + HM450 methylation
(top-10,000 variance probes) as parallel modalities. Plugging METABRIC in
unchanged is not possible — the methylation branch has no input on
METABRIC patients.

## Three honest paths forward

### Path A — RNA-only external validation on METABRIC

Train DMOI on TCGA-BRCA (with both modalities), evaluate on METABRIC by
**zeroing out the methylation branch's input** at inference time. The model
runs end-to-end, but only the RNA pole encoder sees real data.

- **Pro:** METABRIC is the largest, best-annotated external BRCA cohort
  (n ≈ 1,900 with LumA/LumB labels from PAM50).
- **Pro:** Tests the *primary* DMOI claim (hypothesis-conditioned attention
  generalizes) on an independent platform.
- **Pro:** Implementation effort is modest — cohort fetch + label mapping +
  forward pass with `meth = zeros`.
- **Con:** The methylation branch is silenced, so the architecture is being
  evaluated in a degraded mode. We're not really validating the dual-modality
  story.
- **Con:** Probe-vs-microarray gene-expression scale differences will
  require careful normalization (quantile / median-center per cohort).

**Honest framing for v0.2 release:** "DMOI's RNA branch generalizes to
METABRIC at AUROC X — the methylation branch is silenced for this external
test because METABRIC lacks methylation data."

### Path B — Multi-modal external validation on CPTAC-BRCA

CPTAC-BRCA has RNA-seq + DNA methylation (HM450) + proteomics on a
~120-patient cohort (smaller than TCGA-BRCA, but multi-modal).

- **Pro:** Genuine multi-modal external test — both DMOI branches see real
  data.
- **Pro:** PAM50 calls available; cohort_v2-style LumA vs LumB filter is
  straightforward.
- **Con:** Smaller cohort (~120 patients vs METABRIC's ~1,900).
- **Con:** Requires new data ingestion: CPTAC RNA-seq counts (probably
  log2(TPM+1) like TCGA), HM450 IDAT or beta values, sample sheet alignment.
- **Con:** CPTAC is a NIH/NCI consortium cohort — needs dbGaP access for
  controlled-access data. Beta values may be in the open-access bucket.

**Honest framing for v0.2 release:** "DMOI generalizes to CPTAC-BRCA at
AUROC X with both modalities active. Cohort is small but the test is real."

### Path C — Held-out TCGA-BRCA test split (no external cohort yet)

Carve a 20% test split out of TCGA-BRCA cohort_v2 at cohort-construction
time, do all model dev + 5-fold CV on the remaining 80%, then score the
held-out 20% **once** at the end. No external cohort fetched.

- **Pro:** Cleanest train/test separation. Stops the "all reported numbers
  are from the same 417 patients we tuned on" critique.
- **Pro:** Trivially implementable — single change to `build_cohort_v2.py`.
- **Pro:** No new data, no new dependencies.
- **Con:** Still TCGA. Doesn't test cross-cohort generalization at all.
- **Con:** Cuts our cohort_v2 from 417 → 333 (80 % of 417), which makes
  internal CV slightly noisier.

**Honest framing for v0.2 release:** "v0.2 adds a held-out test split
within TCGA. External validation across cohorts is deferred to v0.3."

## Recommendation

If we want a **real** external validation in v0.2 within a single session
of work, **Path A (RNA-only METABRIC)** is the most realistic. Path B is
the most scientifically satisfying but introduces a new data-ingestion
project of nontrivial size. Path C is the cleanest hygiene win but does
not address the cross-cohort question.

A reasonable v0.2 plan that gets us closest to a "the model generalizes"
claim while staying scoped:

1. **Path C first** (carve held-out TCGA test split). One commit, immediate
   honesty gain.
2. **Path A second** (RNA-only METABRIC). One commit, tests the primary
   claim externally.
3. **Path B is v0.3** (CPTAC multi-modal external). Bigger project, do
   when there's runway.

## Open questions for the user

1. Which path(s) to ship in v0.2? (A, B, C, or A+C combined.)
2. If Path B is on the table for v0.3: do we want to start the CPTAC data
   ingestion in the background even before v0.2 ships? (Long download +
   normalization pipeline.)
3. For Path A: do we use **quantile normalization** between TCGA and
   METABRIC expression (most common cross-cohort approach), or
   **median-center per gene** (simpler, less aggressive)?

## Recon update — Path B is NOT feasible on public data

After this design doc was first drafted, a 10-minute GDC API recon found
that the "CPTAC-BRCA has RNA-seq + HM450" assumption above is **wrong**:

| Cohort source | Status |
|---|---|
| CPTAC-3 (GDC `CPTAC-3`, Breast subset) | **1 case** total. Not a cohort. EPIC methylation, not HM450. |
| CPTAC-2 (GDC `CPTAC-2`, Breast subset, ~Mertins 2016) | **134 cases** with RNA-seq, but **ZERO methylation files** on GDC. |
| TCGA-BRCA (GDC) | Only public BRCA source with paired RNA-seq + HM450. |
| METABRIC | RNA microarray only, no methylation. |
| ICGC / GEO singletons | No paired RNA-seq + HM450 at meaningful N. |

The Mertins 2016 CPTAC-BRCA cohort is proteomics + RNA + CNV + WES on
~120 patients — no methylation array was run, so the dual-modality
"Path B" external validation that this doc originally sketched is not
possible on any publicly available BRCA cohort.

**Decision after recon:** v0.2 ships C + A' (TCGA 80/20 holdout +
METABRIC RNA-only with methylation branch silenced). Path B is moved
off the public-data roadmap entirely; a v0.3 multi-modal external would
need a proprietary cohort or a new published study with paired modalities.

The recon trail is preserved here so a future reader doesn't repeat the
half-day of fetch-pipeline work that would have ended in "no data."
